# ByteArena — ігровий магазин

ByteArena — Flask-сайт з каталогом ігор, кошиком, авторизацією, профілями
користувачів, новинами та захищеною адмін-панеллю.

## Структура проєкту

```
logo/
├── app.py                  # Flask-сервер, API, авторизація та база даних
├── logo.db                 # SQLite-каталог, кошик і замовлення
├── users.json              # Користувачі та налаштування профілів
├── html/                   # HTML-сторінки сайту
│   ├── ByteArena.html      # Головна
│   ├── biblioteka.html     # Каталог
│   ├── portfolio.html      # Кошик
│   ├── profil.html         # Профіль
│   ├── admin.html          # Адмін-панель
│   ├── news.html           # Новини
│   └── ...                 # Сторінки окремих ігор
├── css/                    # Стилі сторінок
├── static/js/              # JavaScript
│   ├── auth.js             # Стан авторизації та аватар у навігації
│   ├── games.js            # Завантаження та фільтрація каталогу
│   ├── basket.js           # Кошик і checkout
│   └── admin.js            # Адмін-панель
├── static/games/           # Файли завантаження ігор
└── static/uploads/profiles/# Аватари та фони користувачів
```

## Опис компонентів

### Серверна частина

- `app.py` — Flask-маршрути, REST API, сесії, CSRF і валідація.
- `logo.db` — таблиці `games`, `basket`, `orders` та `order_items`.
- `users.json` — облікові записи, хеші паролів і налаштування профілів.

### Клієнтська частина

- `html/` — сторінки головного меню, каталогу, профілю, новин ігор та адмінки.
- `css/` — адаптивні стилі сторінок, темна/світла тема профілю.
- `static/js/` — логіка авторизації, каталогу, кошика та адмін-панелі.
- `img/` — локальні обкладинки і фонові ресурси.

## Як запустити проєкт

1. Встановіть Python 3.x.
2. Встановіть Flask:
   ```
   pip install flask
   ```
3. Запустіть сервер:
   ```
   python app.py
   ```
4. Відкрийте http://localhost:5500/bytearena у браузері.

Сервер слухає всі мережеві інтерфейси (`0.0.0.0`), тому в локальній мережі
його також можна відкрити за IP-адресою цього комп'ютера. Для доступу з іншого
комп'ютера можуть знадобитися дозвіл Windows Firewall і доступна мережа.
Порт можна змінити змінною `PORT`, а адресу прив'язки — змінною `HOST`.

## Функціонал

- Реєстрація та вхід з підтримкою старих акаунтів.
- Постійна авторизація до 30 днів і вихід з акаунта.
- Каталог із пошуком, фільтрами жанрів і сортуванням.
- 12 ігор у каталозі, зокрема Elden Ring, Cyberpunk 2077, Baldur's Gate 3 і Hades.
- Серверний кошик, зміна кількості товарів, checkout та історія замовлень.
- Профіль із display name, описом, кольором аватара та dark/light theme.
- Власний аватар, фонове фото або відео для кожного користувача.
- Аватар відображається у профілі та навігації всіх основних сторінок.
- Новини про оновлення каталогу, профілі та функції ByteArena.
- Адаптивна верстка для мобільних і десктопних екранів.
- Список бажаного з додаванням і видаленням ігор.
- Відгуки з оцінкою від 1 до 5 для кожної гри.
- Промокоди, зокрема тестовий `WELCOME10` зі знижкою 10%.
- Статуси замовлень: `new`, `paid`, `processing`, `completed`, `cancelled`.
- Сповіщення про оформлення замовлення та зміну його статусу.
- Досягнення за перше замовлення, Wishlist, відгук і п’ять замовлень.
- Порівняння до трьох ігор у каталозі через `localStorage`.
- Окрема сторінка порівняння з ціною, жанром, платформою та рейтингом.

## Оновлена архітектура

### Основні API

- `GET /api/games` — каталог, пошук, жанри та сортування.
- `GET /api/profile` — поточний профіль і замовлення.
- `POST /api/profile/update` — текстові налаштування профілю.
- `POST /api/profile/media` — завантаження аватара або фону.
- `GET /api/basket` — кошик користувача.
- `POST /api/basket/add`, `/update`, `/remove` — керування кошиком.
- `POST /api/basket/checkout` — оформлення замовлення.
- `GET/POST/DELETE /api/wishlist` — список бажаного.
- `GET/POST /api/games/<id>/reviews` — відгуки та оцінки гри.
- `GET /api/notifications` і `POST /api/notifications/read` — сповіщення.
- `GET /api/achievements` — досягнення користувача.

Сторінка `/compare` використовує вибрані в каталозі ігри з ключа
`bytearena-compare` у `localStorage` і підтримує максимум три позиції.

Тема профілю зберігається на сервері та автоматично застосовується на всіх
сторінках після входу. Доступні темна і світла теми.
- `GET /api/admin/summary` — статистика адмін-панелі.
- `GET/POST /api/admin/games` — перегляд і додавання ігор.
- `PUT/DELETE /api/admin/games/<id>` — редагування або видалення гри.
- `GET /api/admin/users` і `/api/admin/orders` — дані для адміністратора.
- `PATCH /api/admin/orders/<id>` — зміна статусу замовлення.

### Адмін-панель

Адмін-панель доступна за адресою `/admin`. Доступ мають лише користувачі,
зазначені у змінній середовища `BYTEARENA_ADMIN_USERS`.

```powershell
$env:BYTEARENA_ADMIN_USERS = "admin,manager"
python app.py
```

Якщо змінну не задано, адміністратором за замовчуванням є користувач `admin`.
Панель дозволяє додавати й видаляти ігри, переглядати користувачів, замовлення,
редагувати ігри, змінювати статуси замовлень, кількість ігор та загальну виручку.

### Безпека та production

- Flask session зберігається до 30 днів і має підпис.
- Для проблем із cookie-сесією використовується підписаний резервний auth-cookie.
- Нові паролі зберігаються через `generate_password_hash`.
- POST, PUT, PATCH і DELETE захищені CSRF-токеном.
- Завантаження профілю обмежені розширеннями та розміром: аватар до 8 МБ,
  фон до 30 МБ.
- Для production потрібно встановити унікальний `BYTEARENA_SECRET_KEY`,
  вимкнути `debug`, обмежити `BYTEARENA_ADMIN_USERS` і використовувати
  production WSGI-сервер.
